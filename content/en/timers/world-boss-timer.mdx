**No live world-boss countdown is available on this page.** We have not verified a boss roster, fixed spawn interval or server-specific next-spawn time. Do not treat the page title as a current spawn alert.

## Before setting an alarm

Read the current in-game notice or official event notice. Record the server, time zone and exact boss name. Distinguish a scheduled appearance from a random spawn window. If a notice does not specify a time, leave it unknown rather than extrapolating a repeat interval from one sighting.

| Record | What to write down |
| --- | --- |
| Server and region | Your current server, not another player's region |
| Boss or event | Exact in-game name |
| Source | Notice URL or dated in-game observation |
| Time and zone | Full date, displayed time and UTC offset |
| Repeat rule | Only the rule explicitly stated in the notice |
| Last checked | Date checked after maintenance or a patch |

## Keep a usable record

Use one shared record for a group and mark observations separately from announced schedules. Recheck it after maintenance. A missed sighting is not proof that the spawn timer changed; the source and observation need to be reviewed first.
