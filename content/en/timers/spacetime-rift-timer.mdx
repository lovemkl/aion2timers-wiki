**This is a schedule-checking guide, not a live rift timer.** A verified opening schedule for your server is not supplied here.

## Verify the event before planning

Check the exact event name in the game and its current official notice. Record region, server, start and end dates, and the time zone printed beside the schedule. Do not copy a recurring interval from an older guide unless the current notice repeats it.

| Field | Required evidence |
| --- | --- |
| Region/server | The server to which the notice applies |
| Active dates | Event start and end, including year |
| Opening time | Explicit time or window in the notice |
| Time zone | UTC offset, including any date change |
| Access conditions | Only requirements stated in the current notice |
| Source checked | Link and review date |

## Put the time in your calendar

Convert the notice's time to your own zone, confirm the resulting calendar date, and label the reminder with the server name. Keep the original source in the calendar note so a changed schedule can be traced. If the source lacks an opening time, leave the reminder unset.

For location records, use the [rift location checklist](/reference/rift-locations).
