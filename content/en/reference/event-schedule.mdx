**This page is not a live event calendar.** We do not publish a verified current reset time or server-specific event schedule here.

## Create a source-linked calendar entry

| Field | Required detail |
| --- | --- |
| Event | Exact name in the current notice |
| Region/server | Applicable audience |
| Start and end | Full date, time and UTC offset |
| Repeat rule | Only if the current notice states one |
| Eligibility | Conditions in that same notice |
| Source and check date | Link plus the date you reviewed it |

A time such as 09:00 is incomplete without a time zone. Converting a time can also change the calendar date. Preserve the source time alongside your local reminder.

## Review after changes

After maintenance or an announcement update, compare the calendar entry with the source again. Do not treat an old daily reset pattern as a permanent promise. Remove expired reminders so past events do not look current.

See the [timer-use guide](/guide/how-to-use-timers) for the difference between source times and personal reminders.
