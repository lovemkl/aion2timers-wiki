**This page does not currently provide an interactive map or a verified coordinate list.** It explains how to record a location without confusing servers, zones or event versions.

## Record a location

| Field | What to capture |
| --- | --- |
| Region and server | Where you observed it |
| Zone | Exact in-game map label |
| Map reference | Screenshot or coordinates if the game exposes them |
| Date and game build | When the observation was made |
| Event/state | Whether the location was active or only marked |
| Source | Your observation or a linked official notice |

Keep an observed location separate from a confirmed recurring spawn point. A single screenshot does not establish a repeat schedule. Avoid inventing coordinates when the source only names a zone.

## Use the record

Compare the map label with your current in-game map before travelling. If a notice or patch changes the event, recheck the location record. Pair a confirmed location with the [schedule checklist](/timers/spacetime-rift-timer); neither a map pin nor an opening time proves the other.
