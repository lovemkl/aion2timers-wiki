**This page is a manual planning reference. It does not contain an interactive build planner.** No automatic damage calculation, equipment database or validated shared-build system is provided.

## Build sheet

| Field | Your record |
| --- | --- |
| Purpose | Activity and constraints for the build |
| Class and level | Values from your character |
| Patch and server | Version and region for the information |
| Skill plan | Link to your allocation notes |
| Equipment | Exact item names and observed stats |
| Source | Current game screen, official notice or attributed test |
| Unknowns | Costs, interactions or requirements not yet checked |

Separate measured results from preferences. A build recommendation without a patch or source should remain a suggestion, not a proven optimum. Copy the sheet before changing an item so comparisons can be traced.

## Apply the plan carefully

Review the current in-game costs and requirements before changing skills or equipment. Change one part at a time when comparing results, record the activity and conditions, and avoid attributing differences to the build if the test conditions also changed.

Use the [skill worksheet](/tools/skill-calculator) to track allocations. It records your inputs and does not validate them.
