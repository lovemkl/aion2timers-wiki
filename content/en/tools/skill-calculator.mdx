**There is no interactive skill calculator on this page.** We have not supplied a verified skill tree, point budget or prerequisite database. The worksheet below helps you record information from your current game build; it does not validate allocations.

## Prepare a build record

| Field | Fill from your current character or current documentation |
| --- | --- |
| Class and level | Exact in-game values |
| Game build or patch | Version/date of the data you use |
| Available points | Value shown by the game |
| Skill and rank | In-game skill name and proposed rank |
| Point cost | Cost displayed at that rank |
| Prerequisites | Explicit requirement shown by the game |
| Remaining budget | Starting budget minus recorded costs |

Record uncertain costs as unknown. A spreadsheet total is only arithmetic; it cannot prove a build satisfies the game rules. Verify prerequisites in the current game before applying the plan.

## Compare two options

Keep each allocation on a separate copy of the worksheet. Note the intended activity and what changes between the options. Do not assume that a guide for another patch has the same costs. Before changing your character, check the current reset conditions in the game rather than relying on a generic claim that resetting is free or cheap.
